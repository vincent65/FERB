EcholoKernel Agent: Detailed Flow Diagrams

All Mermaid diagrams from DETAILED_AGENT_FLOW.md, rendered for visualization.

1. Complete Agent Execution Flow

flowchart TD
    Start([Start Experiment]) --> LoadConfig[Load YAML Config]
    LoadConfig --> InitOptimizer[Initialize Optimizer]
    
    InitOptimizer --> CheckRetrieval{Retrieval
Enabled?}
    CheckRetrieval -->|Yes| InitTritonCorpus[Initialize Triton Corpus
Load reference+solution pairs]
    CheckRetrieval -->|Yes| InitLLMRetriever[Initialize LLM Retriever
For example kernel ranking]
    CheckRetrieval -->|No| SkipRAG[No RAG Retrieval]
    
    InitTritonCorpus --> CheckDocs{Docs Dir
Exists?}
    InitLLMRetriever --> CheckDocs
    SkipRAG --> InitOpenAI
    
    CheckDocs -->|Yes| InitDocsCorpus[Initialize Docs Corpus
Load markdown pages + manifest]
    CheckDocs -->|No| SkipRLM[No RLM Retrieval]
    
    InitDocsCorpus --> InitRLMRetriever[Initialize RLM Retriever
For recursive doc search]
    InitRLMRetriever --> InitOpenAI[Initialize OpenAI Client]
    SkipRLM --> InitOpenAI
    
    InitOpenAI --> InitBootstrap[Initialize Bootstrap Stage]
    InitBootstrap --> InitProposer[Initialize Proposer
with optional retriever]
    InitProposer --> InitMemory[Initialize Memory Strategy
e.g., best_so_far]
    InitMemory --> InitScorer[Initialize Scorer
e.g., speedup_mean]
    InitScorer --> InitEvaluator[Initialize Modal Evaluator]
    InitEvaluator --> CreateRunDir[Create Run Directory
with timestamp]
    CreateRunDir --> InitLogger[Initialize RunLogger
JSONL output]
    
    InitLogger --> BootstrapPhase[BOOTSTRAP PHASE]
    
    BootstrapPhase --> BootLoop{For each
problem}
    
    BootLoop -->|Next Problem| CheckCandidateExists{Candidate
file exists?}
    
    CheckCandidateExists -->|Yes| LogSkipped[Log: bootstrap_skipped_existing]
    CheckCandidateExists -->|No| CheckSeedExists{Seed file
exists?}
    
    CheckSeedExists -->|Yes| CopySeed[Copy from solutions_/
e.g., solutions_triton/]
    CheckSeedExists -->|No| GenerateNew[Generate from scratch]
    
    CopySeed --> LogSeedCopy[Log: bootstrap_seed_copy]
    
    GenerateNew --> LoadReference[Load reference implementation
from reference/id.py]
    LoadReference --> CollectContext[Collect context examples
from other solved problems]
    CollectContext --> BootstrapRLMCheck{RLM Retriever
available?}
    
    BootstrapRLMCheck -->|Yes| BootstrapRLMQuery[Build RLM Query:
Problem ID + Reference snippet]
    BootstrapRLMCheck -->|No| BootstrapNoRLM[No docs retrieved]
    
    BootstrapRLMQuery --> BootstrapRLMCall[Call RLM.retrieve
Recursive doc search]
    
    BootstrapRLMCall --> BootstrapRLMIter{Iteration < Max?}
    BootstrapRLMIter -->|Yes| RLMSelectPages[LLM selects relevant pages
based on query]
    RLMSelectPages --> RLMReadPages[Read page contents]
    RLMReadPages --> RLMAppendContext[Append to context]
    RLMAppendContext --> RLMGenerateFollowup[LLM generates follow-up query
or decides to stop]
    RLMGenerateFollowup --> RLMContinue{Continue
search?}
    RLMContinue -->|Yes| BootstrapRLMIter
    RLMContinue -->|No| RLMConcatDocs[Concatenate all retrieved docs]
    BootstrapRLMIter -->|No| RLMConcatDocs
    
    RLMConcatDocs --> BootstrapBuildPrompt
    BootstrapNoRLM --> BootstrapBuildPrompt[Build Bootstrap Prompt:
- Reference code
- Context examples
- Retrieved docs]
    
    BootstrapBuildPrompt --> BootstrapLLMCall[LLM: Generate Initial Candidate
Returns JSON with candidate_code]
    BootstrapLLMCall --> ValidateBootstrap{Valid code?
Has def solution?}
    
    ValidateBootstrap -->|No| BootstrapError[Raise RuntimeError:
Invalid bootstrap]
    ValidateBootstrap -->|Yes| WriteCandidate[Write to solutions_agent/id_agent.py]
    
    WriteCandidate --> LogGenerated[Log: bootstrap_generated]
    LogGenerated --> SnapshotIter0[Save snapshot:
snapshots/problem_id/iter_0_bootstrap.py]
    LogSkipped --> SnapshotIter0
    LogSeedCopy --> SnapshotIter0
    
    SnapshotIter0 --> AdvanceProgress1[Advance Progress Bar]
    AdvanceProgress1 --> BootLoop
    
    BootLoop -->|All Done| PrecomputeRefs[Precompute Reference Results]
    
    PrecomputeRefs --> RefLoop{For each
problem}
    RefLoop -->|Next| RunRefBackend[Run Modal:
reference backend]
    
    RunRefBackend --> RefModalCmd[modal run run_modal.py]
    
    RefModalCmd --> RefWait{Subprocess
completes?}
    
    RefWait -->|Timeout| RefTimeoutError[Raise RuntimeError]
    RefWait -->|Error| RefCrashError[Raise RuntimeError]
    RefWait -->|Success| RefParseSummary[Parse summary_rank0.json]
    
    RefParseSummary --> RefExtractMetrics[Extract metrics]
    RefExtractMetrics --> RefCache[Cache reference result]
    RefCache --> RefLoop
    
    RefLoop -->|All Done| AdvanceProgress2[Advance Progress Bar]
    AdvanceProgress2 --> MainIterLoop[MAIN ITERATION LOOP]
    
    MainIterLoop --> IterCheck{Iteration < max?}
    
    IterCheck -->|No| EndExperiment[End Experiment]
    IterCheck -->|Yes| EvaluateAll[EVALUATE ALL CANDIDATES]
    
    EvaluateAll --> EvalProblemLoop{For each problem}
    
    EvalProblemLoop -->|Next| GetCachedRef[Get cached reference result]
    GetCachedRef --> RunCandidateBackend[Run Modal: candidate backend]
    
    RunCandidateBackend --> CandModalCmd[modal run run_modal.py]
    
    CandModalCmd --> CandWait{Subprocess completes?}
    
    CandWait -->|Timeout| MakeTimeoutResult[Create Error Result]
    CandWait -->|Error| MakeCrashResult[Create Error Result]
    CandWait -->|Success| CheckSummaryExists{Summary exists?}
    
    CheckSummaryExists -->|No| MakeMissingResult[Create Error Result]
    CheckSummaryExists -->|Yes| ParseCandSummary[Parse summary_rank0.json]
    
    MakeTimeoutResult --> StoreEvalResult
    MakeCrashResult --> StoreEvalResult
    MakeMissingResult --> StoreEvalResult
    ParseCandSummary --> ExtractCandMetrics[Extract metrics]
    
    ExtractCandMetrics --> StoreEvalResult[Store evaluation result]
    StoreEvalResult --> EvalProblemLoop
    
    EvalProblemLoop -->|All Done| ScoreAll[Score All Results]
    
    ScoreAll --> ScoreLoop{For each result}
    ScoreLoop -->|Next| CheckEvalFailed{Eval failed?}
    
    CheckEvalFailed -->|Yes| AssignZeroScore[Assign score = 0.0]
    CheckEvalFailed -->|No| CallScorer[Call Scorer.score]
    
    CallScorer --> SpeedupCalc[Speedup Mean Scorer]
    SpeedupCalc --> StoreScore[Store score]
    AssignZeroScore --> StoreScore
    
    StoreScore --> LogEvalEntry[Log evaluation entry]
    LogEvalEntry --> ScoreLoop
    
    ScoreLoop -->|All Done| ComputeMeanScore[Compute mean score]
    ComputeMeanScore --> AdvanceProgress3[Advance Progress Bar]
    
    AdvanceProgress3 --> CheckEarlyStop{early_stop_speedup?}
    
    CheckEarlyStop -->|Yes| LogEarlyStop[Log: early_stop]
    LogEarlyStop --> EndExperiment
    
    CheckEarlyStop -->|No| ProposalPhase[PROPOSAL PHASE]
    
    ProposalPhase --> PropLoop{For each problem}
    
    PropLoop -->|Next| TakeSnapshot[Take rollback snapshot]
    
    TakeSnapshot --> CheckLatestFailed{Latest eval failed?}
    
    CheckLatestFailed -->|Yes| CaptureFailedCode[Capture failed code]
    CaptureFailedCode --> ExecuteRollback[Rollback]
    CheckLatestFailed -->|No| SkipRollback[No rollback]
    
    ExecuteRollback --> TakeSnapshotAgain[Take new snapshot]
    TakeSnapshotAgain --> DetermineMode
    SkipRollback --> DetermineMode[Determine Proposal Mode]
    
    DetermineMode --> CheckCorrectness{Eval failed OR correctness?}
    
    CheckCorrectness -->|Yes| SetCorrectMode[Mode = correctness_fix]
    CheckCorrectness -->|No| SetPerfMode[Mode = perf_opt]
    
    SetCorrectMode --> BuildProposalContext
    SetPerfMode --> BuildProposalContext[Build Proposal Context]
    
    BuildProposalContext --> GetMemorySummary[Get Memory Summary]
    
    GetMemorySummary --> MemoryStrategy{Memory Strategy}
    MemoryStrategy -->|best_so_far| BuildIterationTimeline[Build iteration timeline]
    MemoryStrategy -->|none| NoMemory[Return empty summary]
    
    BuildIterationTimeline --> FormatMemorySummary[Format as text summary]
    NoMemory --> FormatMemorySummary
    
    FormatMemorySummary --> PropRLMCheck{RLM Retriever available?}
    
    PropRLMCheck -->|Yes| BuildRLMQuery[Build RLM Query]
    PropRLMCheck -->|No| PropNoRLM[retrieved_docs = empty]
    
    BuildRLMQuery --> PropRLMCall[Call RLM.retrieve]
    
    PropRLMCall --> PropRLMConcat[Concatenate retrieved docs]
    PropNoRLM --> AddRLMContext[Add retrieved_docs to context]
    PropRLMConcat --> AddRLMContext
    
    AddRLMContext --> SelectTemplate{Proposal Mode?}
    
    SelectTemplate -->|correctness_fix| UseCorrectTemplate[correctness_patch_template]
    SelectTemplate -->|perf_opt| UsePerfTemplate[performance_patch_template]
    
    UseCorrectTemplate --> FormatPrompt[Format prompt]
    UsePerfTemplate --> FormatPrompt
    
    FormatPrompt --> CheckRAG{RAG Retriever available?}
    
    CheckRAG -->|Yes| LLMWithTools[LLM Call with Tools]
    CheckRAG -->|No| LLMDirect[Direct LLM Call]
    
    LLMWithTools --> ParseProposalJSON
    LLMDirect --> ParseProposalJSON[Parse JSON Response]
    
    ParseProposalJSON --> ValidateProposal{Proposal valid?}
    
    ValidateProposal -->|Invalid| PropRollback[Rollback]
    ValidateProposal -->|Valid| WriteNewCode[Write candidate_code]
    
    WriteNewCode --> SaveIterSnapshot[Save snapshot]
    SaveIterSnapshot --> LogApplied[Log: proposal_applied]
    
    PropRollback --> AdvanceProgress4[Advance Progress Bar]
    LogApplied --> AdvanceProgress4
    
    AdvanceProgress4 --> PropLoop
    
    PropLoop -->|All Done| IncrementIter[Increment iteration]
    IncrementIter --> MainIterLoop
    
    EndExperiment --> WriteSummary[Write summary.json]
    WriteSummary --> PrintPaths[Print output paths]
    PrintPaths --> End([Experiment Complete])

2. RLM (Recursive Language Model) Retrieval Process

flowchart TD
    Start([RLM Retrieval Start]) --> InitVars[Initialize: context, iteration, query]
    
    InitVars --> IterCheck{iteration < max_iterations?}
    
    IterCheck -->|No| ReturnContext[Return concatenated context]
    IterCheck -->|Yes| BuildRankPrompt[Build ranking prompt]
    
    BuildRankPrompt --> CallRankLLM[LLM Call: Rank pages]
    
    CallRankLLM --> ParsePageIDs[Parse page IDs from response]
    
    ParsePageIDs --> ReadPages[Read top-K page contents]
    
    ReadPages --> AppendToContext[Append pages to context]
    
    AppendToContext --> BuildDecisionPrompt[Build decision prompt]
    
    BuildDecisionPrompt --> CallDecisionLLM[LLM Call: Decide next action]
    
    CallDecisionLLM --> ParseDecision{LLM says continue?}
    
    ParseDecision -->|No| ReturnContext
    ParseDecision -->|Yes| ExtractNewQuery[Extract follow-up query]
    
    ExtractNewQuery --> UpdateQuery[Update query variable]
    UpdateQuery --> IncrementIter[Increment iteration]
    IncrementIter --> IterCheck
    
    ReturnContext --> End([Return Retrieved Docs])
    
    style Start fill:#f0e1ff
    style End fill:#f0e1ff

3. RAG Tool-Use Cycle During Proposal

flowchart TD
    Start([Proposer with RAG]) --> InitMessages[Initialize messages]
    
    InitMessages --> SetupTools[Setup tools: search_examples]
    
    SetupTools --> RoundCheck{round < max_tool_rounds?}
    
    RoundCheck -->|No| ForceFinal[Make final call without tools]
    RoundCheck -->|Yes| SendRequest[Send API request]
    
    SendRequest --> GetResponse[Get response]
    
    GetResponse --> ExtractOutputs[Extract output items]
    
    ExtractOutputs --> FilterToolCalls[Filter tool calls]
    
    FilterToolCalls --> HasTools{Has tool calls?}
    
    HasTools -->|No| ParseText[Parse output_text as JSON]
    HasTools -->|Yes| ToolLoop{For each tool call}
    
    ToolLoop -->|Next| ParseArgs[Parse arguments JSON]
    
    ParseArgs --> CallRetriever[Call retriever.retrieve]
    
    CallRetriever --> BuildCorpusSummary[Build corpus summary]
    
    BuildCorpusSummary --> RankWithLLM[LLM ranks corpus entries]
    
    RankWithLLM --> SelectEntries[Select top-K entries]
    
    SelectEntries --> FormatCode[Format as text]
    
    FormatCode --> AppendToolCall[Append to messages]
    
    AppendToolCall --> ToolLoop
    
    ToolLoop -->|All Done| IncrementRound[Increment round]
    IncrementRound --> RoundCheck
    
    ForceFinal --> FinalRequest[Send API request without tools]
    FinalRequest --> FinalResponse[Get response]
    FinalResponse --> ParseText
    
    ParseText --> StripFences[Strip json fences]
    StripFences --> JSONParse[Parse JSON]
    JSONParse --> ExtractProposal[Extract proposal fields]
    
    ExtractProposal --> End([Return PatchProposal])
    
    style Start fill:#e1f0ff
    style End fill:#e1f0ff

4. Evaluation with Error Handling

flowchart TD
    Start([Evaluate Problem]) --> GetCached{Reference cached?}
    
    GetCached -->|No| RunRef[Run reference backend]
    GetCached -->|Yes| SkipRef[Use cached reference]
    
    RunRef --> RefResult{Ref eval result?}
    RefResult -->|Error/Timeout| RaiseError[Raise RuntimeError]
    RefResult -->|Success| CacheRef[Cache reference result]
    CacheRef --> RunCand
    SkipRef --> RunCand[Run candidate backend]
    
    RunCand --> BuildCommand[Build modal run command]
    
    BuildCommand --> StartSubprocess[Start subprocess]
    
    StartSubprocess --> Wait{Wait for completion}
    
    Wait -->|Timeout| HandleTimeout[TimeoutExpired]
    Wait -->|Non-zero exit| HandleError[CalledProcessError]
    Wait -->|Other exception| HandleException[Generic Exception]
    Wait -->|Success| CheckFile{Summary file exists?}
    
    HandleTimeout --> BuildTimeoutResult[Build error result: timeout]
    
    HandleError --> BuildErrorResult[Build error result: error]
    
    HandleException --> BuildExceptionResult[Build error result]
    
    CheckFile -->|No| BuildMissingResult[Build error result: Missing summary]
    
    CheckFile -->|Yes| ReadSummary[Read summary_rank0.json]
    
    ReadSummary --> ParseCorrectness[Parse correctness]
    
    ParseCorrectness --> ParsePerformance[Parse performance]
    
    ParsePerformance --> ParseTraces[Parse traces]
    
    ParseTraces --> BuildFeedback[Build eval_feedback dict]
    
    BuildFeedback --> BuildSuccessResult[Build BackendEvalResult]
    
    BuildTimeoutResult --> ReturnResult
    BuildErrorResult --> ReturnResult
    BuildExceptionResult --> ReturnResult
    BuildMissingResult --> ReturnResult
    BuildSuccessResult --> ReturnResult[Return result pair]
    
    ReturnResult --> End([Evaluation Complete])

5. Memory Strategy - Best So Far

flowchart TD
    Start([Memory.summarize]) --> Input[Input: history list]
    
    Input --> FindBest[Find best entry by score]
    
    FindBest --> BuildSummary[Build text summary]
    
    BuildSummary --> AddBestLine[Add: Best iteration so far]
    
    AddBestLine --> AddLatestLine[Add: Latest iteration]
    
    AddLatestLine --> FormatLoop{For each recent entry}
    
    FormatLoop -->|Next| CheckFailed{Eval failed?}
    
    CheckFailed -->|Yes| FormatFailed[Format: iter N FAILED]
    CheckFailed -->|No| FormatSuccess[Format: iter N score=X]
    
    FormatFailed --> AppendText[Append to summary]
    FormatSuccess --> AppendText
    
    AppendText --> FormatLoop
    
    FormatLoop -->|All Done| AddGuidance[Add: Avoid repeating failed approaches]
    
    AddGuidance --> ReturnSummary[Return formatted summary]
    
    ReturnSummary --> End([Memory Summary])
    
    style Start fill:#fff4e1
    style End fill:#fff4e1

6. Rollback Manager

flowchart TD
    Start([Rollback Manager]) --> Create[Create RollbackManager]
    
    Create --> Snapshot1[snapshot call before proposal]
    
    Snapshot1 --> ReadCurrent[Read current file content]
    ReadCurrent --> StoreContent[Store content in memory]
    
    StoreContent --> GenerateProposal[Agent generates new code]
    GenerateProposal --> Validate{Code valid?}
    
    Validate -->|Yes| Apply[Write new code to file]
    Validate -->|No| NeedRollback[Need to rollback]
    
    Apply --> EvaluateCode[Evaluate new code]
    EvaluateCode --> EvalResult{Eval result?}
    
    EvalResult -->|Success| KeepChanges[Keep changes]
    EvalResult -->|Error/Timeout| NeedRollback
    
    NeedRollback --> RollbackCall[rollback call]
    RollbackCall --> RestoreContent[Write content back to file]
    RestoreContent --> LogRollback[Log rollback event]
    
    LogRollback --> NextIteration[Next iteration]
    KeepChanges --> NextIteration
    
    NextIteration --> Snapshot2[snapshot call for next proposal]
    Snapshot2 --> ReadAgain[Read current file content]
    ReadAgain --> StoreAgain[Update _snapshot_content]
    
    StoreAgain --> End([Ready for next cycle])
    
    style Start fill:#e1f5e1
    style End fill:#e1f5e1

    style RollbackCall fill:#ffcccc

    R -->|false| NoRAG[Direct LLM calls only]
    
    Config --> ES{early_stop_speedup set?}

    SB -->|triton| CopySeed[Copy from solutions_triton/]
    SB -->|other| CopyOther[Copy from solutions_backend/]
    
    Config --> ST{strategies config}
    ST --> Prop[proposer]
    ST --> Mem[memory]
    ST --> Scr[scorer]
